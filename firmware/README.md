# Исходники прошивки MotoKey

MotoKey — небольшой проект контроллера для мототехники. Через Android-приложение контроллер на ESP32 принимает команды по Bluetooth и управляет предусмотренными схемой выходами POWER/START.

Проект находится на раннем этапе: опубликованы первые версии прошивки и приложений. Возможности и документация будут постепенно расширяться. Перед подключением к мотоциклу проверяйте свою схему и сначала тестируйте устройство на безопасном стенде.

## Релизы

Firmware sources are kept by version in this directory. Published binary releases are generated by GitHub Actions and attached to GitHub Releases.

### MotoKey CORE 3.3.0 — Timer START (экспериментальная)

- Source: `MotoKey_CORE_3_3_0_TIMER_START/MotoKey_CORE_3_3_0_TIMER_START.ino`
- Separate authenticated `TIMER_START` command for the watch timer; it requires POWER_ON.
- Manual `START` still requires ARM and the existing 15-second window.
- NVS namespaces retained: `mkpair` and `ierikhon`
- Partition-table SHA-256 verified identical to CORE 3.2.0.
- Published as a GitHub prerelease and selectable in Flasher; CORE 3.2.0 remains the default.
- Compiled successfully; physical bench testing has not yet been completed.

### MotoKey CORE 3.2.0

- Source: `MotoKey_CORE_3_2_0_SHARED_TOKEN/MotoKey_CORE_3_2_0_SHARED_TOKEN.ino`
- Board: ESP32 Dev Module (classic ESP32)
- Arduino-ESP32: 3.3.12
- NimBLE-Arduino: 2.5.2
- Flash: 4 MB, DIO, 80 MHz
- Pairing: one shared token, up to three simultaneous phone clients
- NVS namespaces retained: `mkpair` and `ierikhon`

A release is only published after a successful build and a check that the partition-table SHA-256 matches the previous stable firmware. The workflow updates the Flasher manifest only after uploading the release binaries.
