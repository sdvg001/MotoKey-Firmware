# MotoKey firmware source

## Releases

Firmware sources are kept by version in this directory. Published binary releases are generated by GitHub Actions and attached to GitHub Releases.

### MotoKey CORE 3.2.0

- Source: `MotoKey_CORE_3_2_0_SHARED_TOKEN/MotoKey_CORE_3_2_0_SHARED_TOKEN.ino`
- Board: ESP32 Dev Module (classic ESP32)
- Arduino-ESP32: 3.3.12
- NimBLE-Arduino: 2.5.2
- Flash: 4 MB, DIO, 80 MHz
- Pairing: one shared token, up to three simultaneous phone clients
- NVS namespaces retained: `mkpair` and `ierikhon`

A release is only published after a successful build and a check that the partition-table SHA-256 matches the previous stable firmware. The workflow updates the Flasher manifest only after uploading the release binaries.
