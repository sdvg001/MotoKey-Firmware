# MotoKey CORE 3.3.0 — Timer START (экспериментальная версия)

Основана на CORE 3.2.0 Shared Token. Сохранены общий BLE-токен, до трёх одновременных клиентов и прежние пространства NVS: `mkpair` и `ierikhon`.

## Изменения

- Ручная команда `START` не меняется: по-прежнему требует `ARM` и действует только в пределах 15-секундного окна.
- Для таймера добавлена отдельная команда `TIMER_START`.
- `TIMER_START` доступна только авторизованному BLE-клиенту, когда POWER уже включён и START не активен.
- Используется сохранённая длительность импульса START (500–3000 мс).

## Сборка

- Board: ESP32 Dev Module (classic ESP32), Flash 4 MB
- Arduino-ESP32: 3.3.12
- NimBLE-Arduino: 2.5.2
- Flash: DIO, 80 MHz, default partition table
- Полное стирание Flash отключено.

## Статус

Экспериментальная версия. Перед применением на мотоцикле обязательно проверить на стенде с отключённой цепью стартера: POWER, длительность импульса START, таймер, потерю BLE-связи и повторный запуск таймера. Стабильная версия 3.2.0 остаётся доступной во Флешере и версией по умолчанию.
