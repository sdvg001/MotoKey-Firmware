MotoKey
управление запуском мотоцикла

MotoKey — мой проект контроллера на ESP32. Идея простая: подключить телефон по Bluetooth и управлять питанием и запуском мотоцикла через устройство.

Инструкция по прошивке ↗

Важно: для обычного обновления уже привязанного контроллера не включай флажок сброса привязки в Flasher. Сброс удалит текущие pairing-данные, после чего телефоны придётся подключить заново.

С чего начать

Коротко о первом подключении и настройке.

1
Установи MotoKey Flasher

Запусти Windows-установщик. При необходимости установи .NET 10 Desktop Runtime x64.

2
Подключи ESP32 по USB

Закрой Arduino Serial Monitor и другие программы, которые могут занимать COM-порт. Выбери порт в Flasher.

3
Проверь контроллер

Нажми «ПРОВЕРИТЬ ESP32». Flasher должен подтвердить классический ESP32 и Flash 4 MB.

4
Выбери версию и прошей

Выбери стабильную версию. Flasher проверит кеш и SHA-256, а перед записью — совместимость таблицы разделов/NVS.

5
Сохрани существующую привязку

Для обычного обновления оставь выключенным флажок «Сбросить старую привязку и создать новую».

6
Подключи телефон

Установи официальный APK MotoKey. Для новой платы используй созданный Flasher pairing-код; для уже привязанной платы не сбрасывай привязку без необходимости.

После прошивки проверь работу контроллера на стенде. Не подключай стартер, пока не убедишься, что система работает корректно.
