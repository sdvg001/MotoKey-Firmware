# MotoKey

MotoKey — мой небольшой проект для мототехники. Идея — использовать контроллер на ESP32, чтобы с Android-телефона по Bluetooth управлять питанием и запуском мотоцикла. В этом репозитории лежат прошивка контроллера, мобильное приложение и программа для настройки и обновления через Windows.

**Сейчас это первые рабочие версии проекта.** Я продолжаю проверять и дорабатывать устройство, прошивку и приложение. Дальше будут исправления и новые возможности. Это не универсальное готовое решение для любой модели мотоцикла: перед подключением нужно проверить совместимость платы и своей электрической схемы.

## Скачать прошивку

[**MotoKey CORE 3.2.0 — Shared Token**](https://github.com/sdvg001/MotoKey-Firmware/releases/tag/v3.2.0)

Релиз включает bootloader.bin, partitions.bin, boot_app0.bin, motokey.bin и файл SHA-256. Для обычного обновления рекомендуется использовать MotoKey Flasher: он получает список версий из manifest.json, скачивает недостающие файлы и проверяет их контрольные суммы перед записью.

[**MotoKey CORE 3.3.0 — Timer START (экспериментальная)**](https://github.com/sdvg001/MotoKey-Firmware/releases/tag/v3.3.0)

Версия 3.3.0 добавляет отдельную команду запуска по таймеру. Она доступна для ручного выбора в Flasher; версия по умолчанию остаётся стабильной 3.2.0. 3.3.0 успешно скомпилирована, но ещё не прошла физическую стендовую проверку — перед подключением стартера обязательно протестируй её с отключённой цепью стартера.

## Перед подключением и прошивкой

- Поддерживаемая плата: классический ESP32 с Flash 4 MB.
- Перед проверкой ESP32 закрой Arduino Serial Monitor и другие программы, которые могут занимать COM-порт.
- При обычном обновлении оставляй выключенным флажок **«Сбросить старую привязку и создать новую»**.
- Не используй полное стирание Flash. Flasher проверяет совместимость таблицы разделов/NVS и прекращает операцию при несовпадении.
- Сначала проверь контроллер и всю схему на безопасном стенде. Не подключай стартер и другие исполнительные цепи, пока не убедишься, что всё работает правильно.

## Что изменилось в CORE 3.2.0

- До трёх одновременных BLE-подключений.
- Один общий токен используется подключёнными телефонами.
- Второй и третий телефон получают существующий общий токен после ввода pairing-кода.
- Сценарий подтверждения нового доверенного телефона с первого телефона не используется.
- Разметка раздела NVS совпадает с опубликованной CORE 3.1.0; обычное обновление не запрашивает erase_flash.

## История прошивок

- **3.3.0 — Timer START (экспериментальная)** — отдельная команда для запуска по завершении таймера часов; обычный START по-прежнему требует ARM.
- **3.2.0** — Shared Token: общий токен для нескольких телефонов, до трёх BLE-подключений.
- **3.1.0** — Multi Client: несколько BLE-клиентов и прежняя схема доверенных устройств.
