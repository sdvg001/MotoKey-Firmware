# MotoKey Firmware

Официальное хранилище прошивок для контроллера MotoKey.

## Автообновление MotoKey Flasher

Flasher проверяет файл [manifest.json](./manifest.json) в ветке `main`.

Raw URL:

`https://raw.githubusercontent.com/sdvg001/MotoKey-Firmware/main/manifest.json`

Формат манифеста описан в [manifest.schema.json](./manifest.schema.json). Сами бинарные файлы будут публиковаться в GitHub Releases, а не в истории исходников.

## Безопасность обновления

- Flasher проверяет SHA-256 каждого скачанного файла до прошивки.
- Обычное обновление никогда не запускает `erase_flash`.
- Перед публикацией версии проверяются таблица разделов и совместимость NVS.
- Сохранность ключей сопряжения гарантируется только при неизменной разметке раздела NVS и отсутствии его стирания.
- При ошибке проверки манифеста, URL или хешей прошивка не запускается.

## Статус

Репозиторий подготовлен для автообновления. Пока список версий пуст: бинарные прошивки будут опубликованы после проверки исходников и собранных файлов.
