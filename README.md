# MotoKey Firmware

Официальное хранилище прошивок для контроллера MotoKey.

## Автообновление MotoKey Flasher

Flasher проверяет файл [manifest.json](./manifest.json) в ветке `main`.

Raw URL:

`https://raw.githubusercontent.com/sdvg001/MotoKey-Firmware/main/manifest.json`

Файл манифеста содержит последнюю стабильную версию и список доступных версий. Сами бинарные файлы будут публиковаться в GitHub Releases.

## Безопасность обновления

- Flasher должен проверять SHA-256 каждого скачанного файла перед прошивкой.
- Нельзя выполнять `erase_flash` при обычном обновлении.
- Перед обновлением необходимо проверить совместимость таблицы разделов с установленной версией.
- Сохранность ключей сопряжения зависит от того, что раздел NVS и его расположение не изменяются.
- Если метаданные или контрольная сумма не прошли проверку, прошивку выполнять нельзя.

## Статус

На начальном этапе репозиторий содержит только инфраструктуру обновлений. Бинарные прошивки появятся после проверки исходного кода, таблицы разделов и сборки.
