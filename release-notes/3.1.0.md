# MotoKey CORE 3.1.0 — Multi Client

**Статус:** подготовлен комплект бинарных файлов; GitHub Release пока не создан.

## Сборка

- Плата: ESP32 Dev Module, классический ESP32
- Flash: 4 MB
- Режим: DIO, 80 MHz
- Arduino ESP32 core: 3.3.12
- NimBLE-Arduino: 2.5.2
- Preferences: 3.3.12

## Бинарные файлы Release

| Файл | Адрес |
|---|---:|
| bootloader.bin | 0x1000 |
| partitions.bin | 0x8000 |
| boot_app0.bin | 0xE000 |
| motokey.bin | 0x10000 |

Эти четыре файла взяты строго по `flash_args` и каждый побайтно совпадает с соответствующим диапазоном полного `merged.bin`.

## Сохранение NVS

Новая сборка использует те же Preferences namespaces `mkpair` и `ierikhon`, сохраняет ключи владельца `code`, `token`, `paired` и настройку `pulse_ms`. При запуске новая прошивка не очищает эти пространства.

Таблица разделов новой сборки использует NVS offset `0x9000`, size `0x5000`. Предыдущая сборка также использовала стандартную схему `PartitionScheme=default` на Arduino ESP32 core 3.3.12. До записи Flasher всё равно обязан прочитать таблицу непосредственно с контроллера и отменить обновление, если NVS offset или size отличаются.

Обычное обновление не должно выполнять `erase_flash` и не должно отправлять команды сброса/изменения pairing.
