# MotoKey CORE 3.2.0 — Shared Token

Это одна из первых опубликованных версий проекта MotoKey — контроллера на ESP32 для управления функциями POWER/START мотоцикла через Android-приложение.

## Что изменилось

- До трёх одновременных BLE-подключений.
- Все подключённые телефоны используют один общий токен.
- Второй и третий телефон могут получить существующий токен после ввода общего кода привязки.
- Сценарий подтверждения нового доверенного телефона с первого телефона не используется.
- Разметка NVS проверена на совместимость с 3.1.0.
- Обычное обновление не стирает Flash/NVS и сохраняет существующую привязку.

## Сборка

- Плата: ESP32 Dev Module, классический ESP32
- Arduino-ESP32: 3.3.12
- NimBLE-Arduino: 2.5.2
- Flash: 4 MB, DIO, 80 MHz
