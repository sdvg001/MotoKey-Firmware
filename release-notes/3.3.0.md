# MotoKey CORE 3.3.0 — Timer START (экспериментальная)

**Статус:** экспериментальный предварительный релиз. CORE 3.2.0 остаётся стабильной версией по умолчанию во Flasher.

## Изменения

- Добавлена отдельная BLE-команда `TIMER_START` для завершения обратного отсчёта на часах.
- Команда доступна только авторизованному BLE-клиенту.
- Перед импульсом требуется включённое состояние POWER; активный START блокирует повторный импульс.
- Используется сохранённая длительность импульса START (500–3000 мс).
- Ручной `START` не изменён: требуется `ARM`, действует существующее 15-секундное окно.
- Сохранены пространства NVS `mkpair` и `ierikhon`; таблица разделов совпадает с CORE 3.2.0.

## Сборка

Успешная сборка в GitHub Actions: ESP32 Dev Module, Arduino-ESP32 3.3.12, NimBLE-Arduino 2.5.2, Flash 4 MB, DIO, 80 MHz. SHA-256 четырёх бинарных файлов опубликованы в релизе.

## Важное предупреждение

Автоматическая компиляция и проверки совместимости прошли успешно, но физическое испытание на стенде ещё не выполнено. Перед подключением стартера обязательно проверь работу POWER и импульса START с отключённой цепью стартера. Не считай успешную компиляцию подтверждением безопасной работы на конкретном мотоцикле.
