# MotoKey Apps — Android 1.1.0+4 / Windows Flasher 1.5.0

Это первые опубликованные версии программ для работы с контроллером MotoKey.

## Android 1.1.0+4

Приложение подключается к контроллеру по Bluetooth Low Energy (BLE) и позволяет работать с функциями POWER/START, получать текущее состояние и задавать длительность импульса.

- [Скачать APK](https://github.com/sdvg001/MotoKey-Firmware/releases/download/apps-v1.1.0/app-release.apk)

## Windows Flasher 1.5.0

Программа для подключения контроллера к компьютеру, проверки классического ESP32 с Flash 4 MB, загрузки прошивки и обновления через USB.

- Проверка SHA-256 файлов прошивки.
- Проверка совместимости таблицы разделов/NVS.
- Сохранение существующей привязки при обычном обновлении, если не выбран её сброс.
- Не выполняет полное стирание Flash при штатном обновлении.

- [Скачать Windows Setup x64](https://github.com/sdvg001/MotoKey-Firmware/releases/download/apps-v1.1.0/MotoKeyFlasher-Setup-1.5.0-x64.exe)

## О проекте

MotoKey — небольшой развивающийся проект для мототехники. Это первые версии; приложение, прошивка и само устройство будут постепенно дорабатываться. Если заметишь проблему или у тебя есть предложение, напиши через [GitHub Issues](https://github.com/sdvg001/MotoKey-Firmware/issues).

Перед использованием проверяй подключение и работу контроллера на безопасном стенде.
